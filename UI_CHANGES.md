# Изменения интерфейса игры

## Что было изменено:

### 1. Расширение игрового поля
- **Старая ширина:** 800px
- **Новая ширина:** 950px (+150px для боковой панели)

### 2. Боковая панель справа
- **Ширина:** 250px
- **Цвет фона:** Темно-серый (#222222) с рамкой (#333333)
- **Расположение элементов:**
  - Заголовок "MAZE GAME" вверху
  - Поле "SCORE" с большими цифрами
  - Поле "TIME" с таймером формата MM:SS
  - Инструкции "CONTROLS" с текстом "WASD or ARROWS"
  - Подсказка "R - RESTART"

### 3. Уменьшение поля лабиринта
- **Новая ширина лабиринта:** 750px (вместо 800px)
- **Все элементы лабиринта сдвинуты:**
  - Стены и проходы центрированы в уменьшенном пространстве
  - Выход сдвинут с 700 на 650 по X
  - Бонус сдвинут с 400 на 375 по X
  - Центральные стены центрированы в пространстве 750px

### 4. Новое расположение элементов:

#### Боковая панель (координаты относительно центра 825):
- `825, 100` - Заголовок "MAZE GAME"
- `825, 200` - Счет "SCORE\n0" (двустрочный)
- `825, 300` - Таймер "TIME\n00:00" (двустрочный)
- `825, 420` - "CONTROLS"
- `825, 460` - "WASD or\nARROWS" (двустрочный)
- `825, 520` - "R - RESTART"

#### Игровое поле (координаты относительно центра 375):
- `375, 30` - Верхняя граница
- `375, 570` - Нижняя граница
- `30, 300` - Левая граница
- `720, 300` - Правая граница (было 770)
- `650, 100` - Выход (было 700)
- `375, 250` - Бонус (было 400)

### 5. Визуальные улучшения:
- Разделительная линия между полем лабиринта и боковой панелью
- Большие шрифты для счета и времени (36px)
- Двустрочное отображение "SCORE\n0" и "TIME\n00:00"
- Центрирование всех текстов на боковой панели
- Контрастные цвета: зеленый для заголовков, белый для значений

## Преимущества нового дизайна:
1. **Четкое разделение:** Игровое поле отделено от интерфейса
2. **Фиксированная ширина:** Значения счета и времени не переносятся
3. **Улучшенная читаемость:** Крупные цифры легко видеть
4. **Профессиональный вид:** Структурированный интерфейс
5. **Все управление справа:** Инструкции всегда перед глазами

Игра теперь имеет профессиональный интерфейс с отдельной боковой панелью для статистики и управления.
