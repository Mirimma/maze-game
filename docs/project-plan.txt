## Веб-прототип на TypeScript в стиле черно-белых телефонов Motorola

### Создано: 03.11.2026
### Автор: opencode AI + [ваше имя]

---

## 🎯 **ЦЕЛЬ ПРОЕКТА**
Создать простую игру-лабиринт с шариком в ретро-стиле черно-белых телефонов Motorola:
- Минималистичная графика (черно-белая или ограниченная палитра)
- Простое управление (стрелки/WSAD/касания)
- Несколько уровней с увеличением сложности
- Система бонусов и ловушек
- Прогресс и сохранение результатов

---

## 🏗️ **ТЕХНОЛОГИЧЕСКИЙ СТЕК**

### Основные технологии:
1. **Язык:** TypeScript
2. **Игровой движок:** Phaser.js 3
3. **Сборка:** Vite (быстрый, современный)
4. **Тестирование:** Jest + Cypress
5. **Контроль версий:** Git

### Вспомогательные инструменты:
- Node.js (версия 24.22.1)
- npm (версия 11.19.1)
- Git для контроля версий
- Любой текстовый редактор или IDE (см. ответ на вопрос 2)

## 🎮 **МЕХАНИКИ ИГРЫ**

### Основные элементы:
1. **Шарик:**
   - Черный круг (или пиксельный спрайт)
   - Движение по инерции
   - Отскок от стен под разными углами

2. **Лабиринт:**
   - Стены: сплошные, разрушаемые, подвижные
   - Пол: обычный, скользкий, липкий
   - Специальные зоны: ускорение, замедление

3. **Бонусы (собирать):**
   - ⭐ Звезда: +100 очков
   - ❤️ Сердце: +1 жизнь
   - 🛡️ Щит: временная неуязвимость
   - ⚡ Молния: временное ускорение

4. **Ловушки (избегать):**
   - ⚫ Яма: падение = потеря жизни
   - 🐌 Улитка: замедление на 5 секунд
   - 🔄 Стрелки: изменение управления
   - ⏱️ Часы: уменьшение времени

### Управление:
- **Клавиатура:** Стрелки или WSAD
- **Сенсорный экран:** Swipe в нужном направлении
- **Мышь:** Клик по направлению (опционально)

## 🧪 **ТЕСТИРОВАНИЕ**

### Три уровня тестирования:
1. **Unit тесты (Jest):**
   - Тестирование отдельных функций и классов
   - Физика столкновений
   - Логика игры и правила
   - Система очков и прогресса

2. **Интеграционные тесты (Jest):**
   - Взаимодействие игровых объектов
   - Полные игровые сценарии
   - Сохранение и загрузка прогресса

3. **E2E тесты (Cypress):**
   - Прохождение полного уровня
   - Работа всех меню
   - Отзывчивость интерфейса
   - Кросс-браузерное тестирование

### Цели покрытия тестами:
- Core логика: 90%+
- Игровая механика: 80%+
- UI компоненты: 70%+
