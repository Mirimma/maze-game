## Инструкция по использованию:

1. **Создайте проект** в выбранном сервисе (YouGile/WEEEK/Kaiten)
2. **Создайте колонки** как указано выше
3. **Добавьте задачи** из Backlog вручную
4. **Начните с первой задачи** - "Настроить окружение разработки"
5. **Перемещайте задачи** между колонками по мере прогресса
6. **Используйте чеклисты** для сложных задач
7. **Добавляйте метки** для классификации
8. **Комментируйте прогресс** в задачах
