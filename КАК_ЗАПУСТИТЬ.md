# Как запустить игру "Maze Game"

## Вариант 1: Dev сервер (рекомендуется для разработки)
**Ссылка:** http://localhost:3000

### Шаги для запуска:
1. Убедитесь, что в терминале запущен процесс Vite:
   ```
   npm run dev
   ```
2. Откройте браузер по адресу: http://localhost:3000
3. Игра должна автоматически загрузиться

## Вариант 2: Production preview
**Ссылка:** http://localhost:4173

### Шаги для запуска:
1. Соберите проект (если еще не сделано):
   ```
   npm run build
   ```
2. Запустите preview:
   ```
   npm run preview
   ```
3. Откройте браузер по адресу: http://localhost:4173

## Что должно отображаться:

### Успешная загрузка:
1. Заголовок "🎮 Maze Game"
2. Статус "✅ Задача 1.6: Первая сцена Phaser - ВЫПОЛНЕНО"
3. Черное игровое поле 800x600 пикселей
4. Текст "Загрузка игры..." который исчезнет через 2 секунды
5. Игровые элементы:
   - Черный шарик (управляется WSAD/стрелками)
   - Белые стены лабиринта
   - Зеленый выход (цель)
   - Красный старт
   - Желтая звезда (бонус)
6. Панель управления с инструкциями

### Если игра не отображается:
1. Проверьте консоль браузера (F12 → Console)
2. Убедитесь, что процесс Vite запущен
3. Проверьте, нет ли ошибок в терминале
4. Попробуйте обновить страницу (Ctrl+F5)

## Управление в игре:
- **WASD** или **Стрелки** - движение шарика
- **Цель:** Добраться до зеленого выхода
- **Бонус:** Собрать желтую звезду (+100 очков)
- **Рестарт:** Клавиша R после завершения уровня

## Проверка TypeScript:
Если есть сомнения в корректности кода:
```
npm run typecheck
```
Должен завершиться без ошибок.

## Если ничего не работает:
1. Перезапустите dev сервер:
   ```
   Ctrl+C в терминале с Vite
   npm run dev
   ```
2. Проверьте установлены ли зависимости:
   ```
   npm install
   ```
3. Откройте новое окно браузера в режиме инкогнито (без кэша)
